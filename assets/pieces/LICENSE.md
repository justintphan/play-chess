# Chess piece artwork

The 12 piece images in this folder (`wK.svg` ... `bP.svg`) are the "Cburnett" chess set
by Colin M. L. Burnett, the same set used by Wikipedia and Lichess.

- Author: Colin M. L. Burnett (Cburnett)
- Source: Wikimedia Commons, files `Chess_klt45.svg`, `Chess_qlt45.svg`, `Chess_rlt45.svg`,
  `Chess_blt45.svg`, `Chess_nlt45.svg`, `Chess_plt45.svg` and the matching `...dt45.svg`
  files for the black pieces (https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces)
